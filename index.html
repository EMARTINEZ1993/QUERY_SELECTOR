Guía de proyecto: formularios HTML y JavaScript

Propósito: construir dos formularios, capturar y validar sus datos, guardarlos en el navegador y mostrarlos en la página.

En esta actividad se practica HTML, JavaScript, el DOM, FormData, ciclos y localStorage.

1. ¿Qué hace querySelector()?

document.querySelector() busca en el documento el primer elemento que coincide con un selector CSS y lo devuelve. Así JavaScript puede escuchar eventos o cambiar elementos HTML.

  • document.querySelector("#formulario"): busca el elemento cuyo id es formulario.
  • document.querySelector(".destacado"): busca el primer elemento con la clase destacado.
  • document.querySelector("h1"): busca el primer encabezado h1.

Si no encuentra un elemento, devuelve null. Por eso, el selector debe coincidir con el HTML. En el proyecto, por ejemplo, id="formulario" se conecta con querySelector("#formulario").

2. Estructura de carpetas

Crea una carpeta para el proyecto y dentro de ella conserva esta organización. Los nombres y mayúsculas deben coincidir con las rutas de los archivos:

proyecto-formularios/
├── index.html
├── ejercicio2.html
└── JS/
    ├── app.js
    └── app2.js
  1. index.html contiene el formulario de registro de aprendices.
  2. ejercicio2.html contiene el formulario de registro de mascotas.
  3. La carpeta JS contiene el código que controla cada formulario.

Abre index.html en el navegador. Los datos se guardan en el almacenamiento local de ese navegador; no se envían a un servidor.

5. ¿Qué debes comprobar?

  1. Los archivos están en las carpetas indicadas y los nombres coinciden.
  2. Cada formulario tiene id="formulario" y un espacio de resultados con id="resultado".
  3. La ruta del script es correcta: JS/app.js o JS/app2.js.
  4. Completa el formulario, envíalo y confirma que los datos aparecen.
  5. Recarga la página y comprueba que se conserva el último registro.
  6. En el ejercicio de mascotas, marca varios servicios y comprueba que se guarda el último valor del campo servicios.

Importante: localStorage es útil para practicar, pero no es una base de datos. Los datos quedan guardados solo en el navegador y equipo donde se realizó la actividad.
